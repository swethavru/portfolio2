Chapter 1 · About Me

I build technology for people who need it most

I'm a final-year Computer Science Engineering student with a strong foundation in Python, SQL, and machine learning. I learn by building — when I want to understand something, I don't just read about it, I build a real project around it.

At a hackathon, I built an app that helps deaf individuals identify environmental sounds using ML and audio processing. I built it because the technology to recognize sounds already exists — but it's locked behind expensive, specialized devices. Why should it be?

That question — why should powerful technology be inaccessible to the people who need it most — is the question I want to spend my career answering. It's also the question HENNGE asks every day through their mission of "Liberation of Technology."

Accessibility Sound Recognition App

Python · Machine Learning · Audio Processing · Hackathon

A mobile application that helps deaf individuals identify and interpret environmental sounds in real time — doorbells, alarms, traffic, and more. It uses audio processing and ML to classify sound categories and converts them into visual and vibration alerts, making technology accessible to users with hearing impairments.

CloudGuard — AWS Security Scanner

Python · AWS · Docker · Testing

A lightweight AWS security posture scanner that checks IAM, S3, and EC2 for common misconfigurations — unrestricted security groups, public S3 buckets, users without MFA, wildcard policies, and unencrypted storage. 13 checks with severity scoring, JSON reports, and CI/CD-ready exit codes. 46 unit tests passing.

"Making enterprise-grade security auditing accessible to teams that can't afford expensive commercial tools."
